概述

AI Chat Folders Pro（以下简称「本扩展」）是一款帮助用户在 DeepSeek 和豆包（Doubao）平台上管理对话的浏览器扩展。本隐私政策说明我们如何处理用户数据。

收集我们收集哪些数据

1. 本地存储（不离开浏览器）

以下数据全部存储在你浏览器的 chrome.storage.local 中，不会自动上传：

  • 文件夹结构与分组信息
  • 收藏的对话链接、备注和置顶状态
  • 语言偏好、字体缩放设置
  • 锁屏密码（仅加盐 SHA-256 哈希，无法还原明文）

2. 登录时的最小信息

当你使用微信或 Google 登录时，扩展向后端发送：

  • 浏览器 User-Agent（用于安全审计）
  • IP 地址（用于防止欺诈和设备数量限制）
  • 随机生成的设备 ID（不包含个人信息）

这些信息仅在登录和登出时请求，登录成功后不再重复发送。

3. 版本检查

扩展启动时会向我们的服务器检查是否有新版本，请求不携带任何用户标识。

可选账号相关信息与用户提交内容

  • 邮箱绑定（可选）：用户主动绑定时保存邮箱地址，验证码 5 分钟内有效、用后即删
  • 留言 / 反馈（可选）：用户主动提交时保存留言内容与填写的联系方式，仅用于回复与改进产品
  • 云同步（可选）：登录后上传用户自己整理的文件夹名称、对话标题与对话链接，用于在用户自己的设备间同步

以上内容均不会用于广告、画像或向第三方共享。

不收集我们不做的事

  • 不读取你在 DeepSeek / 豆包的对话内容
  • 不追踪你的浏览历史
  • 不将数据分享给任何第三方
  • 不用于广告投放或行为分析
  • 不在你未登录时发送任何网络请求（除版本检查外）

云端同步可选功能

当你主动登录账号后，文件夹和收藏数据会自动在你登录的设备间同步。同步仅针对你自己的账号，我们不介入也不查看你的数据内容。登出账号后，扩展停止所有网络请求。

数据删除

  • 扩展卸载时，浏览器自动清除所有本地存储
  • 扩展内「导出」功能可将所有数据导出为 JSON 文件
  • 登出账号可停止云端同步

Overview

AI Chat Folders Pro ("the Extension") is a browser extension that helps users organize chat conversations on DeepSeek and Doubao platforms. This privacy policy explains how we handle user data.

Collects What we collect

1. Local storage (never leaves your browser)

The following data is stored entirely in chrome.storage.local and is never uploaded:

  • Folder structure and groupings
  • Favorited chat links, notes, and pin status
  • Language preference and font scale settings
  • Screen lock password (salted SHA-256 hash only, cannot be reversed)

2. Minimal info at sign-in

When you sign in via WeChat or Google, the Extension sends to our backend:

  • Browser User-Agent (for security auditing)
  • IP address (for fraud prevention and device limit enforcement)
  • Randomly generated device ID (contains no personal information)

This info is requested only at sign-in and sign-out time.

3. Version check

At startup, the Extension checks our server for updates without carrying any user identifier.

Optional Account info & user-submitted content

  • Email binding (optional) — stores the email address only if the user chooses to bind one; the verification code expires in 5 minutes and is deleted after use
  • Feedback (optional) — stores the message and the contact info the user types, used only to reply and improve the product
  • Cloud sync (optional) — after sign-in, uploads the folder names, conversation titles and conversation links the user created, solely to sync across the user's own devices

None of this is used for advertising, profiling, or shared with third parties.

Does NOT collect What we never do

  • Never reads your chat content on DeepSeek / Doubao
  • Never tracks your browsing history
  • Never shares data with third parties
  • Never uses data for ads or behavioral analytics
  • Never sends network requests unless you sign in (version check aside)

Cloud sync Optional feature

Once you sign in, folders and favorites auto-sync across your signed-in devices. Syncing is between your own devices only — we do not access or inspect your data. Signing out stops all network activity.

Data deletion

  • Uninstalling the Extension clears all local storage automatically
  • "Export" inside the Extension exports all data as a JSON file
  • Signing out stops cloud sync immediately
